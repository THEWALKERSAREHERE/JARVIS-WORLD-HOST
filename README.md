# JARVIS WORLD HOST — Public Download Site

This folder is the static website for the JARVIS WORLD HOST Phase 2.1 source release.

## Publish with GitHub Pages

1. Create a **new public repository** named `JARVIS-WORLD-HOST` under your GitHub account. Do not change the visibility of the existing `JARVIS-AI` repository.
2. Upload these two files to the repository's root:
   - `index.html`
   - `JARVIS_WORLD_HOST_Phase2_1.zip`
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main**, folder **/(root)**, then save.
6. Wait for GitHub Pages to publish. The site URL will be:
   `https://THEWALKERSAREHERE.github.io/JARVIS-WORLD-HOST/`
